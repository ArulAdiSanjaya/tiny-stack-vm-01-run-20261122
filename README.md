# tiny-stack-vm

A tiny stack virtual machine (Node 22, standard library only). One run
answers all 40 instances of a set: it executes each `program.bin` on its
`input.bin` and writes `stdout.bin` + `exit.txt` per instance. 32-bit
wrapping integers, 256-value stack, 64-deep call stack, 256 words of memory,
and all ten traps with their own exit codes, exactly as the ISA specifies.
